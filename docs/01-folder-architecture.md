# 01. 폴더 구조와 책임

모노레포. 앱 두 개(수업 전 / 수업 중)가 공통 코어를 공유한다.
실행은 분리, 스키마·지식 자산은 공유.

```
nova-coach/
├─ AGENTS.md / CLAUDE.md   # 에이전트 진입점
├─ docs/                   # 기준 문서와 작업 기록
│  ├─ 00~05                # 현재 상태, 구조, 스펙, 제품 계획, 용어집, 코딩 규칙
│  ├─ todo/                # 할 일
│  └─ reports/             # 완료한 일, 주요 결정
├─ packages/
│  └─ core/                # 공통 스키마, 루브릭, 이벤트 형식, 용어집 로더, DB 모델
├─ apps/
│  ├─ studio/              # 배치 분석 (수업 전·후): 지도안 점검, 모의수업 진단, 가상 학생, 실제 수업 사후 분석, 리포트
│  └─ live/                # 수업 중: 실습 진단, 힌트 (오프라인 동작)
├─ services/
│  ├─ asr/                 # Whisper + VAD + 용어 보정
│  └─ llm/                 # 로컬 LLM 서빙 + 하네스 프롬프트
├─ knowledge/              # 루브릭, 오개념 DB, 시나리오, 힌트 라이브러리, 용어집 (사람이 관리)
├─ eval/                   # 정답 전사본, 코딩 정답셋, 일치도 측정
└─ data/                   # 녹화·로그 (git 제외, 암호화)
```

## 책임

| 폴더 | 책임 | 누가 바꾸나 |
|---|---|---|
| `packages/core` | 모든 앱이 공유하는 데이터 형식 | 스키마 변경은 report 필수 |
| `apps/studio` | 배치 분석 + 수업 전 훈련 세션(수업 가이드, 가상 학생 상호작용), 서버에서 실행 | 개발 |
| `apps/live` | 실시간·오프라인, 교실 장비에서 실행 | 개발 |
| `knowledge/` | 평가 기준과 교육 지식 | 커리큘럼팀 확정 |
| `eval/` | 검증 데이터와 스크립트 | 개발 + 전문가 |

## 의존 방향

`apps` → `services` → `packages/core`. 반대 방향 import 금지.
`studio`와 `live`는 서로 import하지 않는다.
