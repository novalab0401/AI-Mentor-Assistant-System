## 목표
회사가 원하는 강사 수준을 관찰 가능한 행동 기준으로 정의한다. (확정은 커리큘럼팀)

## 완료 조건
- [ ] 차원 5~7개 (예: 수업 구조화, 설명 명확성, 발문, 오개념 대응, 시간 관리, 실습 지도)
- [ ] 차원별 수준 3~4단계, 각 단계는 관찰 가능한 행동으로 기술
- [ ] 목표선 (최소 기준) 표시
- [ ] 항목별 측정 유형 표시 (measure / classify / 사람 판단)
- [ ] 항목별 입력 채널 표시 (음성 / 클릭 / 둘 다) — 수업 중 클릭 입력으로 평가 가능한 항목을 구분
- [ ] 시뮬레이션 전용 항목 구분 (원본 4장: 질문 의도 파악, 사고 유도, 돌발상황 대응 등). 검증 전까지 참고용
- [ ] 공식 평가(일반 모의수업) 항목과 참고 평가(시뮬레이션) 항목 구분
- [ ] 우수 강사 인터뷰 결과 반영
- [ ] 커리큘럼팀 확인

## 참고
기존 수업 관찰 체계 (Flanders 상호작용 분석, Danielson, CLASS 등)
