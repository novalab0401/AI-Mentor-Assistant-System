## 요약
가짜 PID 수업 대본 4문장을 원래 표기(`PID`, `P값`, `0.5`)와 발음 표기(`피아이디`, `피값`, `영점오`)로 두 엔진에 읽히고, Whisper small로 다시 받아써서 비교했다.
두 엔진 모두 원래 표기에서 용어·숫자를 틀리게 읽었고, 발음 표기로 바꾸면 알아들을 수 있는 음성이 나왔다. 길이가 안정적인 MeloTTS를 우선 베이스라인으로 둔다. 자연스러움은 사람이 들어서 판단해야 한다.

## 환경과 한계
- CPU 전용 PC(Intel Iris Xe, NVIDIA GPU 없음). 속도 수치는 5090 노트북 기준이 아니다.
- CosyVoice 2는 한국어 화자 프롬프트가 없어 저장소 기본 샘플(중국어 화자)로 cross-lingual 합성했다. 억양 비교는 공정하지 않다.
- 명료도는 Whisper 역전사로만 확인했다. 자연스러움·억양은 측정하지 않았다.

## 결과 (Whisper 역전사)
| 문장 | MeloTTS 원래 표기 | MeloTTS 발음 표기 | CosyVoice 원래 표기 | CosyVoice 발음 표기 |
|---|---|---|---|---|
| s1 `PID 제어` | "귀재열" ✗ | "PID 제어" ✓ | "비어디 체어" ✗, 18.7초 | ✓, 단 24.8초 |
| s2 `P값` | ✓ (자동으로 피값) | ✓ | "피깝스" △ | ✓ |
| s3 `0.5` | "0. 5" ✗ (점 누락) | ✓ | "소우로우 이파이" ✗ (영어 `zero.five`) | ✓, 단 28.8초 |
| s4 의문문 | ✓ | ✓ | "센스업" △ | ✓ |

- 정상 길이는 한 문장 5~9초. CosyVoice 발음 표기 s1·s3는 4~5배 길게 나왔다. 단어는 맞게 받아써졌으므로 침묵이나 웅얼거림이 섞였을 가능성이 높다. 직접 들어서 확인 필요.
- CPU 생성 속도: MeloTTS는 문장당 4~6초, CosyVoice는 실시간 대비 5~6배 느림(RTF 5.4~6.6).
- 원인 확인: MeloTTS는 `PID`를 소문자 `pid`로 남기고 `0.5`를 "영.오"로 변환했다(정규화 결과 직접 출력). CosyVoice는 중국어가 아닌 텍스트를 영어 정규화기와 영어 숫자 읽기로 처리한다(`cosyvoice/cli/frontend.py`의 `text_normalize`, `spell_out_number`).

## 주요 결정
| 결정 | 이유 | 대안 |
|---|---|---|
| TTS 입력 전 발음 정규화 사전을 필수 단계로 둔다 | 두 엔진 모두 영문 약어·소수점에서 실패했고, 발음 표기로 바꾸면 해결됨 | 엔진 내장 정규화에 맡김 |
| 발음 사전은 ASR 보정 사전과 같은 용어집(`knowledge/glossary.yaml`)에서 관리 | 같은 용어의 표기↔발음 쌍을 양방향으로 쓰므로 한 곳에서 관리해야 어긋나지 않음 | TTS 전용 사전 별도 관리 |
| MeloTTS를 우선 베이스라인으로 둔다 (확정 아님) | 길이 안정, CPU에서도 빠름, MIT, 모델이 가벼움 | CosyVoice 2 우선 |
| CosyVoice 2는 탈락시키지 않고 5090 + 한국어 화자 프롬프트로 재시험 | 이번 조건(CPU, 중국어 화자)이 불리했고 길이 이상의 원인을 아직 모름 | 지금 제외 |

## Windows 설치에서 막힌 점 (재현용)
- 공통: uv 가상환경에 `pkg_resources`가 없음 → `setuptools<81` 설치, 빌드 시 `--build-constraint`로 같은 제한.
- MeloTTS: 한국어만 써도 일본어 모듈을 import → 빈 `unidic` 패키지를 제거해 `unidic-lite` 사용. g2pkk는 Windows에서 `eunjeon`(C++ 빌드 필요)만 찾음 → `python-mecab-ko`를 별도 폴더에 설치하고 `eunjeon.Mecab().pos()` 연결 모듈을 둠. 같은 폴더에 설치하면 Windows가 대소문자를 구분하지 않아 일본어 `MeCab` 패키지를 덮어쓴다.
- CosyVoice 2: 경로가 260자를 넘어 transformers 파일이 누락됨(긴 경로 지원 꺼짐) → 가상환경을 짧은 경로에 생성. 모델 4.6GB.
- Whisper 역전사: ffmpeg가 없어 librosa로 16kHz 배열을 만들어 전달.
